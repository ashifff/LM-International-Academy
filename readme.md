# LM International Academy

A professional educational website for **LM International Academy**, designed with a modern, responsive layout and a distinct academic branding.

## 🎨 Design System

The website strictly follows the academy's official branding guidelines:

### **Color Palette**
- **Primary Dark Red:** `#8C2C3F`
- **Secondary Gold:** `#FCB433`
- **Background White:** `#FFFFFF`

### **Typography**
- **Headings:** `Poppins`, sans-serif
- **Body Text:** `Montserrat`, sans-serif

## 📁 Project Structure

The project consists of the following files:

- **`index.html`**: The main landing page.
- **`about.html`**: Information about the academy's mission and vision.
- **`course-grid.html`**: A grid layout showcasing the academic programs.
- **`gallery.html`**: A visual showcase of the campus and activities.
- **`contact.html`**: A contact form and location details.
- **`blog-details.html`**: A template for academy news and articles.
- **`error.html`**: A custom 404 error page.
- **`maintenance.html`**: A temporary page for scheduled downtime.
- **`style.css`**: The main stylesheet controlling the design and layout.
- **`script.js`**: JavaScript for smooth scrolling and interactive elements.

## 🚀 Getting Started

To run this website locally:

1. **Clone or Download** this repository to your local machine.
2. **Open `index.html`** in any modern web browser (Chrome, Firefox, Safari, etc.).
3. **Add your own images** to the root directory (e.g., `hero-image.jpg`, `campus.jpg`) to complete the visual setup.

## 📱 Features

- **Responsive Design:** Adapts seamlessly to mobile, tablet, and desktop screens.
- **Semantic HTML5:** Built with accessibility and SEO best practices in mind.
- **Interactive Elements:** Smooth scrolling and hover animations powered by CSS and JavaScript.
